# Screenshots

Drop the main dashboard screenshot here as `main.png` (referenced from the
top-level README).

Suggested capture:
- Fullscreen at 1920×1080 or larger
- A representative layout (a couple of clocks, primary/secondary timer,
  perhaps an Ontime widget and a HyperDeck widget)
- Edit mode **off** so the dock and per-widget controls are hidden

```bash
# Linux: capture and crop with grim/slurp (Wayland) or import (X11)
grim -g "$(slurp)" screenshots/main.png
```
